# 乐谱 → NS2 指法：转换器的逻辑

[English](score-to-fingering.md) · [返回 README](../README.zh-CN.md)

转换器把用音名写的旋律，转成 Switch 2 版《时之笛》陶笛的按键输入。核心就是一张查找表，加一个可选的移调步骤。代码：[`src/ocarina.mjs`](../src/ocarina.mjs)。

## 1. 输入与输出

| | |
| --- | --- |
| **输入** | 科学音名（`C4`、`F#4`、`Eb5`、`F♯4`），`\|` 表示小节线，`r` 表示休止 |
| **选项** | `transpose`（移调半音数）或 `auto`（自动选最容易弹的移调） |
| **输出** | 每个音对应：按键，加上可选的十字键和/或左摇杆方向，例如 `R + 摇杆 ↑` |

```
$ node bin/score-to-ns2.mjs "E5 D5 C5 B4 | A4 G4" --lang zh
移调：+0 个半音（音域 B3–F5）

E5   →  X + 摇杆 ↑
D5   →  X
C5   →  Y + 十字键 ↑
B4   →  Y

A4   →  A
G4   →  R + 摇杆 ↑
```

## 2. 模型

内部用 MIDI 数字表示音高（C4 = 60），移调就是加减法。

- 5 个按键，基础音高固定：`L` = D4（62）、`R` = F4（65）、`A` = A4（69）、`Y` = B4（71）、`X` = D5（74）。
- 两个修饰：十字键 ↑/↓ = ±1 个半音，左摇杆 ↑/↓ = ±2 个半音。

```
音高 = 按键基础音 + 十字键 + 2 × 摇杆        十字键、摇杆 ∈ {−1, 0, +1}
```

枚举 5 个键 × 3 × 3 得到 **45 种输入**，落在 **19 个音**上（59–77，即 B3–F5）。这张表在加载时生成一次，代码里只写死了 5 个基础音和音域。为什么这个音域没有空洞，见[技术分析](technical-analysis.zh-CN.md#3-数学45-种输入19-个音)。

## 3. 怎么选最简输入

大多数音有多种输入，用一个代价来排序：

| 规则 | 代价 |
| --- | --- |
| 每按一次十字键 | 1 |
| 每推一次摇杆 | 1.5（摇杆没有十字键精准） |
| 代价相同 | 优先选靠前的按键（L、R、A、Y、X），再选总弯音量小的 |

代价最小的输入胜出。对全部 19 个音，结果都和已发布指法表里的“最简输入”一致，并有单元测试检查，所以规则和指法表不会各说各话。

## 4. 处理流程

```
"E5 D5 | C5"
   │ tokenize        音符 / 小节线 / 休止
   ▼
parseNote            "F#4" → 66        （升号、降号、♯ ♭）
   │
   ▼
移调                 不移调、固定移调、或 auto
   │
   ▼
bestFingering        MIDI → { button, dpad, stick }
   │
   ▼
describe             "R + 摇杆 ↑"（中/英）和简写 "R S↑"
```

## 5. 移调

陶笛的音域是 59–77。旋律最低音为 `lo`、最高音为 `hi` 时，能让所有音都可弹奏的移调量恰好是：

```
59 − lo  ≤  移调量  ≤  77 − hi
```

- **没有可用的移调量**（区间为空）：旋律跨度超过 18 个半音。转换器会报告跨度并停止，不会悄悄改音。
- **指定了 `transpose`**：有音超出音域时，报错会列出这些音和可用的移调区间。
- **`auto`**：在所有可用的移调量里选总输入代价最小的，代价相同时选绝对值最小的。对《卡农》开头（D 大调，起音 F♯5，高出一个半音），可用移调量是 −10 到 −1，`auto` 选 **−2**（C 大调），总代价最小。

## 6. 边界情况

- 等音写法（`C#4` / `Db4`）对应同一个 MIDI 数字，得到同一个输入。
- 输出的音名统一用升号（`F♯4`）。
- 休止和小节线原样保留，输出和输入对得上。
- 八度沿用游戏的记谱音高（L = D4 … X = D5），说明见 [README](../README.zh-CN.md#资料来源)。

## 7. 暂不支持

为了让第一版保持简单，刻意没做：

- **音乐上的选调**：`auto` 只看输入代价，短乐句可能选出带临时升降号的移调（例如 `E5 D5 C5 B4 A4 G4` 移 −2 会出现 A♯4 和 F4）。以后可以加一个尽量保持原调性格的选项。`n- **节奏和调号**：输入只是音符列表，升降号要写在每个音上。
- **手指移动的优化**：每个音单独选最简输入。更聪明的做法是考虑上一个音，比如 `E5 → D5 → C5` 只用摇杆在 `X` 键上完成。
- **其他输入格式**：简谱、ABC、MusicXML、MIDI。
- **网页界面**：在浏览器里直接运行这个模块。

## 8. 用法

```bash
# 命令行
node bin/score-to-ns2.mjs "C4 D4 E4 F4 G4 A4 B4 C5"
node bin/score-to-ns2.mjs "F#5 E5 D5 C#5" --auto --lang zh
node bin/score-to-ns2.mjs --file melody.txt --transpose -2 --json

# 作为库
import { convert } from './src/ocarina.mjs';
const { shift, events } = convert('E5 D5 C5', { auto: true });
```

用 `npm test` 运行测试（Node.js 18+，无依赖）。
